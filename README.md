# Blepis LoRa addon

LoRa addon for Blepis, v2! Project started by Spongeboi, v2 upgraded by Ambra and reviewed by Arya.

This addon is for Blepis v2 pinout.

Currently, the pinout of the addon is flipped - so the addon needs to be flipped to match,
with components facing the Blepis (flat side of the PCB facing up) and pin headers soldered
in reverse =(

v3 of this PCB will address this issue, change the modem to one that supports LongFast well (or whatever the issue was),
as well as add an EEPROM for addon identification.

## Notes

- Pin headers are arranged in a way that this board can be plugged into a breadboard.
- I recommend a stencil for assembling this board.

## Info

- Software: KiCad 9
- Version: 2
- PCB size: 60.5*24.2mm
- Layer count: 2
